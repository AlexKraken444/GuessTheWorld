# GuessTheWorld 🌍

Игра на Next.js App Router, React, TypeScript и Supabase, подготовленная для Vercel. Интерфейс на русском. Регистрация по email, одиночная игра, комнаты по коду на 2–8 игроков, интерактивный Google Street View с перемещением, выбор точки на Google Maps, пять двухминутных раундов, таблица результатов и переигровка после согласия всех участников.

## Запуск

Нужен Node.js 22.13+ (для встроенного запуска TypeScript-тестов) или Node.js 24.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

В PowerShell: `Copy-Item .env.example .env.local`. Откройте http://localhost:3000. Главная страница работает без ключей, полноценная игра требует настройки ниже.

## Supabase

1. Создайте проект на https://supabase.com.
2. Выполните `supabase/schema.sql` в SQL Editor.
3. В Authentication → Providers включите Email. Подтверждение email поддерживается: пользователь подтверждает почту, затем входит. Для публичного проекта подключите свой SMTP.
4. В Authentication → URL Configuration укажите Site URL вашего сайта и добавьте `http://localhost:3000` и URL Vercel в Redirect URLs. Для preview deployments добавьте соответствующие адреса.
5. Скопируйте Project URL, клиентский anon key и серверный service_role key в переменные ниже. **Service role никогда не должен иметь префикс NEXT_PUBLIC и не должен попасть в Git.**

## Google Maps

Создайте Google Cloud проект, подключите billing и включите **Maps JavaScript API** и **Street View Static API**. Второй API используется сервером только для metadata, чтобы находить доступные панорамы и их точные координаты.

- `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`: браузерный ключ, разрешён Maps JavaScript API. Ограничьте HTTP referrers вашими доменами (`https://your-app.vercel.app/*`, `http://localhost:3000/*`).
- `GOOGLE_MAPS_SERVER_KEY`: отдельный серверный ключ, разрешён Street View Static API. HTTP referrer restriction к серверному ключу не подходит. У стандартных Vercel функций нет фиксированного исходящего IP; используйте API restrictions и квоты, либо статический egress, если нужен IP allowlist.

Не отключайте атрибуцию Google. Стоимость и лимиты зависят от Google Cloud. Установите квоты в консоли. Панорамы выбираются случайно в окрестностях 30 городов, покрытых Street View; это не равномерная выборка по всей поверхности Земли. Доступность и возможность перемещения определяются покрытием Google.

Официальная документация: [Street View](https://developers.google.com/maps/documentation/javascript/streetview), [API keys](https://developers.google.com/maps/api-security-best-practices).

## Деплой на Vercel

1. Импортируйте GitHub-репозиторий в Vercel, Framework Preset: **Next.js**.
2. Node.js: **24.x**, команды сборки и установки стандартные (`npm run build`, `npm ci`).
3. Добавьте все пять переменных из `.env.example` в Settings → Environment Variables:

| Переменная                      | Назначение                         |
| ------------------------------- | ---------------------------------- |
| NEXT_PUBLIC_SUPABASE_URL        | URL проекта Supabase               |
| NEXT_PUBLIC_SUPABASE_ANON_KEY   | Публичный ключ Supabase            |
| SUPABASE_SERVICE_ROLE_KEY       | Только серверный секрет Supabase   |
| NEXT_PUBLIC_GOOGLE_MAPS_API_KEY | Ключ для браузерных карт           |
| GOOGLE_MAPS_SERVER_KEY          | Ключ для поиска панорам на сервере |

4. Укажите домен деплоя в Supabase и ограничениях браузерного ключа Google.
5. Нажмите Deploy. После изменения переменных выполните Redeploy, поскольку NEXT_PUBLIC значения встраиваются при сборке.

## Правила и архитектура

Создатель запускает матч и следующие раунды. В multiplayer все начинают с одной панорамы, но ходят независимо. Координаты цели не возвращаются API до завершения раунда. Каждый игрок отправляет только один ответ. По истечении 120 секунд незаполненный ответ даёт 0 очков. Расстояние считается по формуле гаверсинуса; очки — `round(5000 * exp(-distanceKm / 2000))`. Побеждает наибольшая сумма за пять раундов; при равенстве объявляется ничья.

Комнаты и результаты хранятся в PostgreSQL Supabase, а не в памяти функций Vercel. Клиент опрашивает сервер раз в 2 секунды. Обновления комнаты используют optimistic concurrency по полю version: одновременные ответы и голоса не затирают друг друга. Таймер проверяется на сервере при запросах; если все закрыли сайт, раунд завершается при следующем запросе. Ответы соперников скрыты до итогов. RLS закрывает таблицу для браузерных клиентов, сервер проверяет токен и членство в комнате. Комната восстанавливается после обновления страницы.

«Главная» закрывает интерфейс комнаты, но сохраняет участие игрока до конца матча. Отключившийся игрок получает 0 за пропущенные раунды; его согласие тоже необходимо для переигровки. Если участник ушёл окончательно, создайте новую комнату. Историю комнат можно периодически удалять SQL-задачей в Supabase. Защиты от профессионального читинга через внутренние данные Google Street View нет: идентификатор панорамы необходим браузеру для просмотра.

## Проверка

```bash
npm run typecheck
npm test
npm run build
```

После настройки сервисов проверьте двумя разными аккаунтами в разных браузерах: регистрацию, вход, код приглашения, одинаковую стартовую панораму, движение, ответы, истечение таймера, пять раундов, согласие на переигровку и восстановление комнаты после перезагрузки. Реальные Google Maps и Supabase нельзя проверить без рабочих ключей.
